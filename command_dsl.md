# Command DSL — NSPE
- `:FOCUS_ENTITY_[Name]:` → Zoom on thinker/concept; saturate with J314/REN evidence.
- `:FORCE_EXPANSION:` → Elaborate under-dense region to meet target density.
- `:VOID_RETREAT:` → Erase last segment; regenerate purified articulation.
- `:INJECT_SOURCE_[RefID]:` → Insert explicit citation (J314 id, REN episode).
- `:EXPORT_METRICS:` → Emit current dashboard without advancing φ-Loop.
- `:PAUSE_PROCESS:` / `:TERMINATE_PROCESS:` → Control loop execution.
